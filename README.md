# Conference Rooms — releases

Installers and the auto-update feed for the **Conference Rooms** desktop widget.

- **Install:** download `ConferenceRooms-Setup-<version>.exe` from the [latest release](../../releases/latest) and run it. It installs per-user, with no admin rights needed.
- **Updates:** installed copies check this repo automatically and update themselves.

This repo holds only release files. The source code is in a private repository.
